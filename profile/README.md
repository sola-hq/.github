# Sola

**Readable code. Verifiable systems.**

Sola builds open-source infrastructure, protocol tooling, and developer utilities for systems that need to be easy to inspect, run, and reason about.

## Focus Areas

- Solana indexing and protocol tooling
- Wallet, SDK, and transaction infrastructure
- Cryptography and MPC experiments
- Observability, tracing, and backend utilities
- Rust and TypeScript developer tooling

## Engineering Principles

- Keep interfaces explicit
- Prefer simple, inspectable designs
- Make behavior testable and reproducible
- Document enough for another engineer to continue the work
- Build in public when it helps the ecosystem

## Selected Projects

- [carbon](https://github.com/sola-hq/carbon) - Solana indexing framework
- [token-2022](https://github.com/sola-hq/token-2022) - SPL Token 2022 program and clients
- [omniqueue-rs](https://github.com/sola-hq/omniqueue-rs) - queue abstraction layer for Rust
- [tracing-otel-extra](https://github.com/sola-hq/tracing-otel-extra) - observability utilities
- [sola-ts-sdk](https://github.com/sola-hq/sola-ts-sdk) - TypeScript SDK tooling
- [mpc-go](https://github.com/sola-hq/mpc-go) - MPC-related engineering work
